Implement agent metadata enhancement and fix chat navigation

Root Cause Analysis:
Two separate issues were addressed: (1) Chat navigation from Agent Details
page was broken due to URL format mismatch (/chat?agent={name} vs
/?agent={name}), discovered during UAT testing. (2) Agent metadata was
limited to basic info - users needed comprehensive details including source
code, tools, model info, and system prompts to understand agent capabilities.

What Was Fixed/Added:
- Fixed chat navigation URL from /chat?agent={name} to /?agent={name}
- Created S3 bucket for agent source code storage with versioning
- Implemented AST-based metadata extraction (tools, model ID, system prompts)
- Added S3 upload for agent source code during CDK deployment
- Enhanced SSM parameters with tools, model, system-prompt, source-code-s3-key
- Updated Lambda to fetch source code from S3 with presigned URLs
- Added Python syntax highlighting with react-syntax-highlighter
- Created system prompt display component
- Added long description support with post-deployment script
- Created About FAST page with project information
- Updated navigation: root redirects to /agents, FAST logo links to /about
- Created Cognito token helper script for API testing
