Implement comprehensive observability dashboard with sessions, metrics, and traces

Root Cause Analysis:
AgentCore Runtime does not provide a direct session listing API. Session data must be extracted from OpenTelemetry (OTEL) spans stored in CloudWatch Logs aws/spans log group. This required implementing custom Lambda functions to query, parse, and aggregate OTEL span data to provide session visibility, metrics aggregation, and detailed trace viewing capabilities.

What Was Fixed/Added:
- Implemented Observability Sessions API Lambda to query CloudWatch Logs OTEL spans and parse session data
- Implemented Observability Metrics API Lambda to aggregate metrics from spans
- Implemented Observability Traces API Lambda to retrieve detailed trace data
- Created comprehensive Observability Dashboard frontend with two-tab interface (Metrics and Sessions)
- Integrated inline trace viewer into chat interface for real-time debugging
- Fixed agent filtering bug with client-side filtering and improved backend agent name extraction
